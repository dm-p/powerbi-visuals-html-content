# Refactoring the sanitizer safely — byte-equivalence as the oracle

## Context

The certified sanitizer (`src/sanitize/`) is a frozen security boundary backed
by a large XSS corpus. A big complexity-reduction + dedup refactor (2026-06-30:
the cc=62 `uponSanitizeAttribute` hook → a gate dispatcher, file relocations,
and unifying four duplicated dangerous-pattern lists) risked silently changing
*what the sanitizer blocks*. "Tests pass" is not sufficient assurance here — a
regression is an XSS hole, and the unit suite may not cover the exact input a
change affects. This is the method that made the refactor safe.

## Guidance

**1. The equivalence oracle is `docs:check` byte-equivalence, not just green tests.**
`docs/sanitization-rules.md` (and the UAT corpus) are *generated by running the
live sanitizer* over the payload corpus. So after every behavior-preserving
step, `npm run docs:generate` must produce **no diff** and `npm run docs:check`
must pass **without regeneration**. Byte-identical generated output ⇒
byte-identical behavior on every corpus input — a far stronger signal than a
passing assertion. Pair it with the full unit suite (including
`security-*.test.ts`) and the 147 real-browser integration tests.

**2. Extract verbatim.** When pulling logic into helpers/gates, copy regexes,
string literals, branch order, and edge cases character-for-character. Do not
"improve" while extracting. Gate/check **order is security-load-bearing** —
preserve it exactly. (Confirm the `�` vs literal `�`, the `\s*` placements,
and capture-group fallbacks match the source.)

**3. Dedup may only WIDEN detection, never narrow.** When unifying pattern
lists onto a canonical source, **spread verbatim copies** of the shared
patterns — do NOT regenerate regexes from scheme strings. The originals carry
subtle whitespace tolerance (`/data\s*:\s*text\/html/i`) that a naive generator
silently narrows. Guard it **permanently** with a superset-assertion test that
freezes the pre-refactor lists (by literal / `RegExp.source`) and asserts
`current ⊇ frozen` — so any future narrowing fails CI, not just this PR.
(See `test/dangerous-patterns-superset.test.ts`.)

**4. Regenerate ALL derived artifacts** if output *does* change — both
`docs:generate` and `uat:generate`. See [[regenerate-sanitizer-derived-artifacts-2026-06-30]].

**5. Mind the CodeScene tax.** Clearing real hotspots is worth it — splitting
the cc=62 hook into named, individually-tested gates was a genuine clarity win
(5.7 → 9.68 health). But chasing the last fraction by extracting one-line
predicates (`isObjectWith`, `isExemptWhitespaceControl`) is pure linter tax:
the helper adds indirection a reader must follow, and inlining it re-trips the
exact "Complex Conditional" metric. Decompose for human clarity; stop when the
only thing left to gain is the score.

## Why This Matters

A sanitizer regression is a security vulnerability, and the failure mode is
silent — the build is green, the demo works, and a payload that used to be
blocked now renders. Byte-equivalent generated output and a superset-assertion
test convert "I believe this is behavior-preserving" into a checkable,
permanent invariant. They are the difference between hoping and knowing.

## When to Apply

- Any extraction/decomposition/relocation under `src/sanitize/`.
- Any edit to the dangerous-scheme/scripting pattern constants.
- Any "behavior-preserving" claim on the certified sanitizer.

## Examples

The 2026-06-30 refactor (branch `refactor/sanitizer-health`):
- cc=62 `uponSanitizeAttribute` hook → a `Verdict`-based gate dispatcher over
  pure gates in `attribute-policy.ts`; the 977 behavior tests proved the swap
  equivalent; `docs:check` stayed green without regeneration at every step.
- Four duplicated dangerous-pattern lists unified onto
  `src/sanitize/dangerous-patterns.ts` by spreading verbatim `SCHEME_REGEXES` /
  `SCHEME_SUBSTRINGS`; `docs:check` stayed byte-equivalent (no widening even),
  and `test/dangerous-patterns-superset.test.ts` (95 assertions) locks in
  "never narrows."
- Final holistic security review verified equivalence by reading the diff, not
  trusting the green suite.
